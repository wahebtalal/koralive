# Koralive - Static HTML Page

A modern, responsive static HTML website for Koralive.

## Features

- 🎨 Modern gradient design
- 📱 Fully responsive layout
- ✨ Smooth animations and transitions
- 🔗 Smooth scrolling navigation
- 📧 Contact form functionality
- ⚡ Lightweight and fast

## File Structure

```
.
├── index.html      # Main HTML file
├── style.css       # CSS styling
├── script.js       # JavaScript functionality
└── README.md       # This file
```

## Sections

- **Navbar**: Sticky navigation with smooth scrolling
- **Hero**: Eye-catching welcome section
- **About**: Company information
- **Services**: Three service cards with hover effects
- **Contact**: Contact form
- **Footer**: Copyright information

## How to Use

1. Clone or download this repository
2. Open `index.html` in your web browser
3. Customize the content to fit your needs

## Customization

### Change Colors
Edit the color values in `style.css`. The main gradient colors are:
- Primary: `#667eea`
- Secondary: `#764ba2`

### Update Content
Edit the text in `index.html` to match your brand and services.

### Deploy with GitHub Pages
1. Go to your repository settings
2. Navigate to "Pages" section
3. Select "Deploy from a branch"
4. Choose the branch with your files (usually `main`)
5. Your site will be live at `https://wahebtalal.github.io/koralive/`
